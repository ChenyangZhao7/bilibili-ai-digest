# 视频报告（video-filter）

粘贴一个 B站 链接，得到一份带时间戳的报告：讲了什么、值不值得看、哪几段值得点回去看。

- **有字幕的视频**：走 B站字幕接口，几秒拿到全文
- **没有字幕的视频**：自动下载音频，用本机语音识别转文字（需要装一次组件，约 1.5GB）
- **报告**：一句话结论 + 分章节要点 + 值得看的片段 + 关键名词，所有时间戳都能点回原片

## 启动

双击 `start.bat`。浏览器会自动打开 `http://127.0.0.1:4318`。

关掉那个黑色窗口 = 关闭服务。再次使用就再双击一次。

## 首次使用要做的两件事

1. **扫码登录 B站**：设置页 →「扫码登录」→ 用手机 B站 扫码。只用来读取字幕，不做任何写操作。登录态一般能撑几个月。
2. **填 AI key**：设置页 →「AI 接口」，默认 `https://api.deepseek.com/v1` + `deepseek-chat`，把你的 key 粘进去，点「保存」，再点「测试连接」确认。

可选第三步：**装语音识别组件**（设置页最下面，约 1.5GB）。不装也能用，只是遇到没有字幕的视频会失败并提示你去装。

## 怎么用

1. 复制 B站视频链接（`bilibili.com/video/BV...`、`b23.tv/...`、纯 BV 号都行）
2. 粘进首页输入框，点「生成报告」
3. 页面显示进度，生成完会跳到报告页，标签标题变成「✓ 报告已生成」并响一声

多 P 视频在链接里带 `?p=2` 就分析第 2P；已有报告 24 小时内直接复用，想重来就勾「强制重新生成」。

## 常见问题

**「登录已过期」/ 抓不到字幕**
设置页重新扫码即可。报告里没字幕时会自动走语音识别，慢但不会中断。

**「B站限流了」**
B站 对频繁请求有限制，等一分钟再点重试。连续失败就先歇会儿。

**语音识别组件下载不动**
GitHub 和 HuggingFace 在国内经常抽风。安装失败时，把提示里的文件手动放到 `downloads/` 目录，再点一次安装，程序会跳过已存在的文件。

**识别的文字有错**
会错。BGM 大、多人抢话、方言都不太行。报告顶部会标注「文字来自语音识别」。

**数据存在哪**
全部在 `data/app.db`（SQLite）。删掉这个文件 = 清空所有报告和配置。`bin/`、`models/` 是语音识别组件，也可以随时删。

**会上传到哪**
除了文字稿发给**你自己配置的 AI 接口**，什么都不外传。服务只监听 `127.0.0.1`，同一 wifi 下的其它设备访问不到。

## 开发

```powershell
npm start          # 启动
npm test           # 跑全部测试（node:test，不需要额外框架）
node scripts/smoke.ts BV1GJ411x7h7   # 对正在跑的服务做一次端到端冒烟
```

代码是 TypeScript，Node 24 直接跑，没有构建步骤。目录结构见 `docs/superpowers/specs/2026-11-16-bilibili-video-report-design.md`。
