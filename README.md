# video-filter

粘贴一个 B站链接，得到一份带时间戳的可读报告。不想看的视频，读报告就够了。

有字幕的视频走 B站字幕接口（几秒出文字）；没有字幕的自动降级到本机语音识别（几分钟）。

## 启动

双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:4318`。

## 首次使用要做的两件事

1. **扫码登录 B站**：设置页点「扫码登录」，用手机 B站扫码。只用来读取字幕，不做任何写入操作。
2. **填 LLM key**：设置页填 DeepSeek 的 API key（默认接口 `https://api.deepseek.com/v1`，模型 `deepseek-chat`）。一个视频通常几分钱。

## 数据存在哪

全部在本机 `data/app.db`（SQLite）。删掉这个文件等于清空所有报告与配置。

> 只监听 `127.0.0.1`，同一局域网的其它设备访问不到。
